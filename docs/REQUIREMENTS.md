# 要件定義書

## 1. プロジェクト概要

### 1.1 目的
商品在庫（洋服・雑貨など）の棚卸し作業を効率化するWebアプリケーション

### 1.2 背景・課題
- 現状は紙に商品名・金額・個数を手書きで記録
- 正の字でカウントしており、数百点の商品を扱うには非効率
- 複数人での同時作業時に重複カウントのリスクがある

## 2. システム概要

### 2.1 利用者
- 4人（最大同時接続数: 4）

### 2.2 利用環境
- **デプロイ先**: ローカルPC上のDockerコンテナ（クラウドデプロイなし）
- **アクセス方法**: 同一WiFiネットワーク内のデバイスからブラウザでアクセス
- **対応デバイス**: スマートフォン、タブレット

### 2.3 利用頻度
- 月1回程度

## 3. 機能要件

### 3.1 商品管理

#### データ構造
商品は **階層構造** で管理する:

```
商品（カテゴリ）
├── 価格1 → SKU（カウント対象）
├── 価格2 → SKU（カウント対象）
└── 価格3 → SKU（カウント対象）
```

- **商品**: 靴、財布などの商品カテゴリ
- **価格**: 商品のサブカテゴリとして登録（同じ商品でも価格帯が異なるものを管理）
- **SKU**: 商品 × 価格 の組み合わせ。棚卸しでカウントする最小単位

#### 商品登録
- 商品（カテゴリ）を登録
- 商品の下に価格を追加・削除・編集可能
- 棚卸し中でも新規商品・価格を追加可能

例:
```
靴: 1600円, 2700円, 3900円
財布: 2700円, 3900円, 5000円
```

#### 商品マスタの引き継ぎ
- 前回の棚卸しで登録した商品・価格を次回に引き継ぐ
- 数量のみ0にリセットして新しい棚卸しを開始

### 3.2 棚卸し作業

#### 棚卸しセッション
- 「新規棚卸し開始」で前回データを引き継ぎ、数量を0リセット
- 棚卸しは途中で中断・再開可能

#### カウント操作
- **+1ボタン**: タップで数量を1増やす
- **直接入力**: 数字を直接入力して設定

#### 複数人同時作業
- 複数人が同時に異なる商品をカウント可能
- 各商品に「担当者」を表示し、誰がカウント中か確認できる（重複対策）

### 3.3 出力・集計

#### CSV出力
- 棚卸し結果をCSVファイルとしてダウンロード
- 出力項目: 商品名、価格、数量、（小計）など

#### 集計表示
- 商品種類（商品名）別の合計金額
- 全体の合計金額
- ※詳細はバックエンド設計時に詰める

## 4. 非機能要件

### 4.1 ユーザビリティ
- スマホ・タブレットで片手操作しやすいUI
- タップしやすいボタンサイズ

### 4.2 パフォーマンス
- 同時接続数: 最大4人
- 商品数: 数百点規模

### 4.3 可用性
- ローカル環境での利用のため、インターネット接続不要

### 4.4 拡張性
- 将来的にFastAPIコンテナを追加してデータ分析機能を追加する可能性あり

## 5. 画面一覧（想定）

| 画面名 | 概要 |
|--------|------|
| ホーム | 棚卸し開始・再開、過去の棚卸し一覧 |
| 棚卸し | 商品一覧表示、カウント操作、商品追加 |
| 集計 | 種類別・全体の合計金額表示 |
| CSV出力 | ダウンロード画面 |

## 6. 用語定義

| 用語 | 定義 |
|------|------|
| 棚卸しセッション | 1回の棚卸し作業の単位。開始から完了（CSV出力）まで |
| 商品 | 靴、財布などの商品カテゴリ |
| 価格 | 商品のサブカテゴリ。同一商品でも価格帯が異なるものを管理 |
| SKU | 商品 × 価格 の組み合わせ。棚卸しでカウントする最小単位 |
| 担当者 | 棚卸し作業に参加しているユーザー |
